# Bruno | Consultor Imobiliário

Site de prospecção de clientes para consultoria imobiliária, com foco em captura de leads via WhatsApp.

## 🏠 Sobre o Projeto

Landing page moderna e responsiva desenvolvida para ajudar na prospecção de clientes interessados em:

- Compra de imóveis
- Venda de imóveis
- Avaliação gratuita
- Investimento imobiliário

## ✨ Funcionalidades

- Design responsivo (funciona bem no celular e computador)
- Botão flutuante do WhatsApp
- Formulário de captura de leads que envia direto para o WhatsApp
- Seções de serviços e diferenciais
- Layout limpo e profissional

## 🚀 Como usar

1. Clone ou baixe este repositório
2. Abra o arquivo `index.html` no navegador
3. Substitua `55SEUNUMEROAQUI` pelo seu número de WhatsApp (com código do país e DDD)
4. Personalize os textos conforme necessário
